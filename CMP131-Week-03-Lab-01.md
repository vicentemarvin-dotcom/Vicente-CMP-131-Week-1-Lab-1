# CMP 131 – Python Programming


> **Required file location:** Keep every Python file directly in the repository root. Do not create a `src` folder.

## Week 3 – Lab 1: Character Profile and Favorite Quote

### Learning Objectives

After completing this lab, students should be able to:

* Create and run a basic Python program.
* Display information using appropriate output statements.
* Work with text and numeric information.
* Organize program output using headings, labels, and spacing.
* Display quotation marks and punctuation correctly.
* Format output so it is clear and visually attractive.
* Follow the required file and folder organization.

## Assignment Overview

Create a Python program that displays information about a fictional character or entity.

You may select a character from a:

* Book
* Movie
* Television show
* Video game
* Comic book
* Mythological story

You may also create your own original fictional character.

The program must display the character’s name, age, occupation or role, and at least three additional attributes or interesting facts.

Extend the program by displaying your favorite quote and identifying the quote’s author or speaker.

Format the information neatly using appropriate headings, labels, blank lines, and decorative characters.

## Required Python File

Create a Python file named:

`character_profile.py`

Include a comment header at the beginning of the file containing:

* Student name
* Course number
* Week number
* Lab number
* Assignment title
* Date

## Part 1: Character Information

Select one fictional character or entity.

Display the following required information:

* Name
* Age
* Occupation or role

The age may be an estimate if the character’s exact age is unknown.

Do not use a real person for this part of the assignment.

## Part 2: Additional Attributes

Display at least three additional attributes or interesting facts about the selected character.

Possible attributes include:

* Residence or home
* Special ability
* Favorite activity
* Personality
* Strength
* Weakness
* Mission or goal
* Favorite food
* Companion
* Important accomplishment
* Interesting fact

You may select other appropriate attributes that fit your character.

Each attribute must include a clear label so the reader can easily understand the information.

## Part 3: Favorite Quote

Add a separate section that displays your favorite quote.

The quote section must include:

* A heading identifying the section.
* The complete quote.
* Quotation marks around the quote.
* The name of the quote’s author or speaker.
* Appropriate spacing between the quote and the character profile.

The quote does not have to come from the fictional character selected for the first part of the assignment.

## Part 4: Output Formatting

Format the output so that it is neat, attractive, and easy to read.

The output must include:

* A descriptive program title.
* A separate heading for the character profile.
* A separate heading for the favorite quote.
* Clear labels for every item.
* Blank lines between major sections.
* Consistent capitalization and spacing.
* Decorative characters to separate sections.
* Quotation marks around the favorite quote.

Possible decorative characters include:

* Equal signs
* Hyphens
* Asterisks
* Number signs

Students should design their own output layout. The instructor is not providing a completed program or exact output design.
